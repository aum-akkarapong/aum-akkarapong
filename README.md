## About

I build tools that make networks visible and systems safer, from packet-level traffic analysis to real-time system monitoring, and I teach what I learn through interactive learning platforms.

My focus is defensive security and network engineering: packet capture and protocol decoding, rule-based detection mapped to MITRE ATT&CK, and SOC-style dashboards for alert triage. On the networking side I work from the wire up, covering Ethernet and switching, IP addressing and subnetting, OSPF and BGP routing, NAT and ACLs, aligned with the CCNA 200-301 topics.

I also deliver production web systems for clients with React, TypeScript, Node.js, Python and SQL, including multi-role dashboards, real-time data and AI automation.

I am looking for roles in Network Engineering, Security Operations (SOC / Blue Team) or Full-Stack Development.

## Engineering Principles

**Defensive by design.** Passive analysis only, safety policies before any destructive action, and every action recorded in an audit log.

**Honest data.** If a value cannot be measured, it is shown as unavailable with a reason, never as a guess.

**Tested and validated.** Unit and end-to-end tests, schema-validated content and continuous integration on every push.
