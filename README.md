- 🛡️ **Security-minded engineer.** I build defensive tooling: packet capture and protocol decoding, rule-based detection mapped to MITRE ATT&CK, and SOC-style dashboards for triage.
- 🌐 **Networking from the wire up.** Ethernet and switching, IP addressing and subnetting, routing (OSPF, BGP), NAT, ACLs, aligned with the CCNA 200-301 topics.
- 💻 **Full-stack delivery.** Production web systems for clients with React, TypeScript, Node.js, Python and SQL, including multi-role dashboards, real-time data and AI automation.
- 🎯 **Looking for** roles in Network Engineering, Security Operations (SOC / Blue Team) or Full-Stack Development.

## How I build

- **Defensive by design.** Passive analysis only, safety policies before any destructive action, and every action recorded in an audit log.
- **Honest data.** If a value can't be measured, it is shown as unavailable with a reason, never as a guess.
- **Tested and validated.** Unit and end-to-end tests, schema-validated content and CI on every push.
